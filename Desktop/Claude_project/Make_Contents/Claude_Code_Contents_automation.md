# YJ-Content Factory — SW 요구사항 명세서 작성 요청

아래 요구사항을 기반으로 **SW 요구사항 명세서를 HTML 문서 1개**로 작성해줘.
이 문서는 "Living Document"로서, 앞으로 계속 수정·보완해나갈 설계도야.
디자인은 다크 테마 기반, 한국어, 보기 좋고 전문적으로 만들어줘.

---

## 1. 프로젝트 개요

### 프로젝트명: YJ-Content Factory
- 부부 크리에이터(윤진 + 영준)의 콘텐츠 자동화 시스템
- 개발 도구: Claude Code (CLI)
- 개발자: 영준 / 사용자: 윤진(콘텐츠), 영준(콘텐츠+개발)

### 핵심 비전
정해진 포맷의 Input만 넣으면, 블로그/인스타/유튜브 콘텐츠가 자동 생성되는 프로그램.
최종적으로는 만들어진 산출물 기반으로 Vix(AI 영상 생성 툴)를 연동해 영상까지 자동 생성.

## 2. 채널 구성 (확정 사항)

### 윤진 채널 — 요리 + 육아 (하나의 채널로 통합 운영)
- 콘텐츠 카테고리: 요리 레시피, 육아 일상/꿀팁, 교차 콘텐츠(아이 간식, 이유식 등)
- 플랫폼: Instagram (릴스+캐러셀+스토리), YouTube (쇼츠+롱폼), 네이버 블로그

### 영준 채널 — 재테크 · 투자 · 절세 경제 채널
- 콘텐츠 카테고리: 퀀트 투자(오늘의 매매 지침), 재테크 기초/포트폴리오, 절세 팁
- 플랫폼: YouTube (쇼츠+롱폼), Instagram (캐러셀+릴스), 네이버 블로그
- 특이사항: 영준이는 이미 퀀트 앱(YJ-Quant, Streamlit 기반)을 운영 중이며, 이 앱에서 매일 "오늘의 지침"(어떤 종목을 어떤 비율로 매수/매도할지)이 텍스트+화면 캡처 형태로 나옴. 이 지침 데이터를 그대로 Input으로 넣으면 콘텐츠가 자동 생성되어야 함.
- 중요: 투자 콘텐츠의 모든 Output에는 "투자 권유가 아닙니다" 면책 조항이 자동 삽입되어야 함.

### 부부 시너지 (향후)
- 윤진 요리 × 영준 재테크 콜라보 콘텐츠 (예: "월 식비 30만원 집밥 챌린지")

## 3. 윤진 파이프라인 — 2단계 워크플로우

### Phase A: 촬영 전 — "어떻게 찍을지 가이드"

**Input (텍스트만, 영상 없음 — 아직 안 찍었으니까):**
- 요리명
- 재료 + 양
- 조리 과정 (순서)
- 나만의 꿀팁 / 실패 포인트
- 비하인드 에피소드
- 목표 영상 러닝타임 (30초/60초/90초 등)

**Output (촬영 가이드 — 이걸 보고 촬영함):**
- A1. 영상 시나리오: 전체 영상 구조, 타임라인, 후킹 문장, BGM 분위기
- A2. 촬영 대본: 타임코드별 멘트, 액션 지시, 표정 가이드
- A3. 촬영 구도/앵글 가이드: 장면별 삼각대 위치·높이·각도, 앵글(탑뷰/45도/정면/클로즈업), 조명 팁, 카메라 이동 타이밍, 흔한 실수 경고, 반드시 찍어야 할 장면 TOP 5, 완성 비주얼 샷 가이드
- A4. 차별화 포인트: 경쟁 채널 대비 차별점, 시리즈화 가능성
- A5. 촬영 체크리스트: 요리 전/장비/촬영 중/놓치면 안 되는 것/촬영 후 체크

**핵심 포인트:** Phase A의 Output은 "이렇게 찍어라"는 실행 가이드. 영상이 아직 없는 상태에서 텍스트만으로 생성. 윤진이가 태블릿에 띄우거나 프린트해서 보고 촬영.

### ↓ 윤진이가 가이드를 보고 촬영 ↓

### Phase B: 촬영 후 — "찍은 영상으로 콘텐츠 생성"

**Input:**
- 촬영된 영상 파일 (.mp4)
- Phase A에서 저장된 레시피 데이터 (자동 연결)
- (선택) 촬영 중 변경 메모
- (선택) 완성 요리 사진

**처리:**
- Whisper STT로 음성→자막 추출
- FFmpeg/OpenCV로 키프레임·썸네일 후보 추출
- 장면 전환 감지

**Output:**
- B1. 편집 가이드: 삭제 구간(타임코드+이유), 배속 구간, 슬로우모션 추천, 자막(타임코드+텍스트), 텍스트 오버레이, BGM 전환, 효과음, 편집 후 예상 길이
- B2. 인스타그램 패키지: 릴스 캡션+해시태그, 캐러셀 5~7장 텍스트, 스토리 문구, 썸네일 추천
- B3. 네이버 블로그 글: SEO 최적화 제목, 본문(서론-재료표-과정-팁-마무리), 사진 위치 표시, 태그
- B4. 유튜브 패키지: 쇼츠 제목+설명+태그, 롱폼 챕터 구성
- B5. 수익화 연결: 쿠팡파트너스 추천 상품, 협찬 가능 카테고리, 시리즈화 가능성

### 육아 콘텐츠
- 레시피 카드 대신 "에피소드 카드" Input 사용 (에피소드 제목, 아이 나이, 상황, 교훈/팁, 감정 흐름 등)
- Phase A/B 구조는 동일하되 Input 포맷만 다름

## 4. 영준 파이프라인

### 퀀트 지침 → 콘텐츠

**Input:**
- 퀀트앱 "오늘의 지침" 텍스트 데이터 (JSON 형태: 날짜, 시장 요약, 전략명, 매매 시그널(종목+비율+근거), 리스크 레벨, 핵심 지표(VIX, Fear&Greed 등))
- 퀀트앱 화면 캡처 이미지 (대시보드, 레이더 차트 등)
- (선택) 영준이 코멘트
- (선택) 시장 이슈 키워드

**Output:**
- E1. 유튜브 영상 대본: 오프닝 후킹, 시장 상황, 전략 해설, 근거, 리스크 경고, CTA
- E2. 영상 구성/설계 전략: 화면 구조, 차트 배치, 자막 스타일, 참고 영상 스타일
- E3. 인스타 캐러셀: 5~7장 슬라이드 텍스트, 후킹 표지, 캡션+해시태그
- E4. 블로그 분석 글: 시장 분석, 전략 설명, 차트 삽입 위치, 면책 조항, SEO 태그
- E5. 쇼츠/릴스 스크립트: 60초 이내 대본

### 재테크/절세 콘텐츠
- 별도 Input 포맷: 주제, 핵심 포인트, 타깃, 참고 링크, 영준이 경험담
- Output은 E1~E5와 동일 구조

## 5. 시스템 아키텍처

### 공통 엔진
- ContextBuilder: 채널 프로필 + Input → 프롬프트 조립
- ContentGenerator: Claude API (Sonnet 4) 호출 + JSON 응답 파싱
- OutputFormatter: 각 플랫폼 포맷으로 변환 + Markdown 저장
- VideoAnalyzer: Whisper STT + FFmpeg + OpenCV (Phase B 전용)

### 파이프라인 라우터
- Streamlit UI에서 윤진 탭 / 영준 탭 선택
- 각 탭에서 Input 입력 → 적절한 파이프라인으로 라우팅 → Output 표시

### 기술 스택
| 구분 | 기술 | Phase |
|------|------|-------|
| 언어 | Python 3.11+ | 1 |
| AI 엔진 | Claude API (Sonnet 4) | 1 |
| UI | Streamlit | 1 |
| 데이터 | JSON → SQLite | 1→3 |
| STT | Whisper (로컬 or API) | 2 |
| 영상 처리 | FFmpeg + OpenCV + PySceneDetect | 2 |
| 영상 생성 | Vix (AI 영상 생성) | 3 |

## 6. 개발 로드맵 (4-Phase)

### Phase 1 — MVP (2주): 텍스트 Input → 촬영 전 가이드
- 윤진 Phase A (레시피 → 시나리오+대본+구도+차별화+체크리스트)
- 영준 기본 (퀀트 지침 → 유튜브 대본+영상 전략)
- Streamlit 2탭 UI

### Phase 2 — 영상 분석 + 멀티 플랫폼 (3주)
- 윤진 Phase B (영상 분석 → 편집 가이드+인스타+블로그+유튜브)
- 영준 확장 (인스타 캐러셀+블로그+쇼츠)
- 육아 콘텐츠 에피소드 카드 추가

### Phase 3 — Vix 영상 자동 생성 (4주)
- 산출물(대본+구도+자막+이미지) → Vix API → 완성 영상(.mp4) 자동 생성
- 직접 촬영 vs AI 생성 하이브리드 전략

### Phase 4 — 완전 자동화 + 시너지 (장기)
- 인스타/유튜브 성과 데이터 연동 → 프롬프트 자동 최적화
- 부부 콜라보 콘텐츠 자동 제안
- 예약 발행 API 연동

## 7. 미결 사항 (HTML 문서에 별도 섹션으로 표시)

아래 항목들은 "미정" 상태로 표시해줘. 추후 확정하면서 문서를 업데이트할 예정:
- 윤진 채널명
- 영준 채널명
- 윤진 채널 톤앤무드 (반말? 해요체? 따뜻한 언니? 등)
- 영준 채널 톤앤무드 (전문적? 친근한? 데이터 중심? 등)
- 타깃 시청자 구체화 (각 채널 페르소나)
- 퀀트앱 지침 JSON 스키마 최종 확정
- Vix API 스펙/가격/한국어 지원 사전 조사
- 수익화 전략 우선순위
- GitHub 레포 구조

## 8. HTML 문서 요구사항

- 다크 테마 기반, 전문적이고 세련된 디자인
- 상단에 네비게이션 (섹션 간 이동)
- 파이프라인은 시각적 다이어그램으로 표현 (Input → 처리 → Output 흐름)
- 확정 사항 vs 미결 사항이 한눈에 구분되도록
- 윤진 관련은 따뜻한 컬러(주황/코랄 계열), 영준 관련은 시원한 컬러(파랑 계열)로 시각 구분
- 로드맵은 타임라인 형태로 시각화
- 변경 이력(버전 로그) 섹션 포함
- "Living Document" — 지속적으로 수정/보완할 수 있는 구조
