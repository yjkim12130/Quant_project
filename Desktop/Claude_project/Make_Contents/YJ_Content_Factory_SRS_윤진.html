윤진 Studio

요리 · 육아 콘텐츠 크리에이터 윤진을 위한 독립 콘텐츠 자동화 시스템. 정해진 포맷의 Input만 넣으면 촬영 가이드가 나오고, 촬영 후 영상으로 블로그 · 인스타 · 유튜브 콘텐츠가 자동 생성된다. 최종적으로 AI 영상 생성(Vix)까지 연결된다.

채널 주제 · 요리 + 육아 사용 · 윤진(콘텐츠 제작) 개발 · 영준(시스템) · Claude Code 최종 수정 · 2026-06-09
01

프로젝트 개요

콘텐츠 제작의 반복 작업을 자동화하여 윤진의 제작 시간을 줄이고, 영상 자산을 체계적으로 축적하는 것을 목표로 한다. 영준 Lab(재테크) 채널과는 완전히 분리된 독립 채널이다.

핵심 비전

정해진 포맷의 레시피·에피소드 Input만 넣으면, 촬영 가이드부터 블로그 · 인스타 · 유튜브 콘텐츠까지 자동 생성되는 프로그램. 최종적으로는 산출물을 기반으로 Vix(AI 영상 생성 툴)를 연동해 영상까지 자동 생성한다.

제작 주체

  • 윤진 — 콘텐츠 기획 · 촬영 · 제작
  • 영준 — 시스템 개발 · 유지보수 (콘텐츠 제작에는 미관여)

산출 대상 플랫폼

네이버 블로그 Instagram (릴스·캐러셀·스토리) YouTube (쇼츠·롱폼) → Vix 영상 (Phase 3)

03

콘텐츠 파이프라인

촬영 전(가이드 생성)과 촬영 후(콘텐츠 생성)로 나뉘는 2단계 워크플로우. 두 단계는 레시피 데이터로 자동 연결된다.

PHASE A · 촬영 전

"어떻게 찍을지" 가이드 생성 — 영상이 없는 상태에서 텍스트만으로 생성. 윤진이 태블릿/프린트로 보고 촬영.

INPUT · 텍스트
  • 요리명
  • 재료 + 양
  • 조리 과정 (순서)
  • 꿀팁 / 실패 포인트
  • 비하인드 에피소드
  • 목표 러닝타임 (30·60·90초)
→
처리 · Claude
  • 채널 프로필 + Input 조립
  • 촬영 가이드 생성
→
OUTPUT · 촬영 가이드
  • A1 영상 시나리오
  • A2 촬영 대본
  • A3 구도/앵글 가이드
  • A4 차별화 포인트
  • A5 촬영 체크리스트
A1
영상 시나리오전체 영상 구조 · 타임라인 · 후킹 문장 · BGM 분위기
A2
촬영 대본타임코드별 멘트 · 액션 지시 · 표정 가이드
A3
촬영 구도/앵글 가이드장면별 삼각대 위치·높이·각도 · 앵글(탑뷰/45도/정면/클로즈업) · 조명 팁 · 카메라 이동 타이밍 · 흔한 실수 경고 · 반드시 찍어야 할 장면 TOP 5 · 완성 비주얼 샷
A4
차별화 포인트경쟁 채널 대비 차별점 · 시리즈화 가능성
A5
촬영 체크리스트요리 전 · 장비 · 촬영 중 · 놓치면 안 되는 것 · 촬영 후 체크
↓  윤진이가 가이드를 보고 촬영  ↓
PHASE B · 촬영 후

찍은 영상으로 멀티 플랫폼 콘텐츠 생성. Phase A의 레시피 데이터가 자동 연결됨.

INPUT
  • 촬영 영상 (.mp4)
  • Phase A 레시피 (자동 연결)
  • (선택) 촬영 중 변경 메모
  • (선택) 완성 요리 사진
→
처리 · 영상 분석
  • Whisper STT 자막 추출
  • FFmpeg/OpenCV 키프레임·썸네일
  • 장면 전환 감지
→
OUTPUT · 멀티 플랫폼
  • B1 편집 가이드
  • B2 인스타그램 패키지
  • B3 네이버 블로그 글
  • B4 유튜브 패키지
  • B5 수익화 연결
B1
편집 가이드삭제 구간(타임코드+이유) · 배속 구간 · 슬로우모션 · 자막(타임코드+텍스트) · 텍스트 오버레이 · BGM 전환 · 효과음 · 예상 길이
B2
인스타그램 패키지릴스 캡션+해시태그 · 캐러셀 5~7장 텍스트 · 스토리 문구 · 썸네일 추천
B3
네이버 블로그 글SEO 제목 · 본문(서론-재료표-과정-팁-마무리) · 사진 위치 · 태그
B4
유튜브 패키지쇼츠 제목+설명+태그 · 롱폼 챕터 구성
B5
수익화 연결쿠팡파트너스 추천 상품 · 협찬 가능 카테고리 · 시리즈화 가능성
04

육아 콘텐츠

요리와 동일한 Phase A/B 구조를 그대로 쓰되, Input 포맷만 "에피소드 카드"로 교체한다.

에피소드 카드 (Input 포맷)

  • 레시피 카드 대신 "에피소드 카드" Input 사용
  • 구성 항목: 에피소드 제목 · 아이 나이 · 상황 · 교훈/팁 · 감정 흐름 · 목표 러닝타임
  • Phase A/B 구조와 A1~A5 · B1~B5 산출물은 요리와 동일 (레시피 → 에피소드 맥락으로 치환)
💡 교차 콘텐츠(아이 간식·이유식)는 레시피 카드 + 에피소드 카드를 함께 입력해 한 번에 처리한다.

06

개발 로드맵

텍스트 가이드 MVP → 영상 분석 → AI 영상 생성 → 완전 자동화의 4단계 진화.

Phase 1 — MVP2주텍스트 Input → 촬영 전 가이드
  • Phase A (레시피 → 시나리오+대본+구도+차별화+체크리스트)
  • Streamlit 단일 채널 UI
Phase 2 — 영상 분석 + 멀티 플랫폼3주
  • Phase B (영상 분석 → 편집 가이드+인스타+블로그+유튜브)
  • 육아 콘텐츠 에피소드 카드 추가
Phase 3 — Vix 영상 자동 생성4주
  • 산출물(대본+구도+자막+이미지) → Vix API → 완성 영상(.mp4) 자동 생성
  • 직접 촬영 vs AI 생성 하이브리드 전략
Phase 4 — 완전 자동화장기
  • 인스타/유튜브 성과 데이터 연동 → 프롬프트 자동 최적화
  • 예약 발행 API 연동
