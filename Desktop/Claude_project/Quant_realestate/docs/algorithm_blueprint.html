Quant_realestate · Algorithm Blueprint v1

YJ-RealEstate 설계도

YJalgo(주식 퀀트)의 동일자산군 상대평가·검증 인프라를 부동산에 이식한 개인용 매수 의사결정 시스템. 서울 남부 11개구 + 경기 남부 핵심 11개시, 5년 실거래 174만 건 기반.

기준일 2026-08-15 매매 352,000건 · 전세 1,385,477건 선택엔진 검증 통과 p<0.001 레짐 장기검증 통과 p<0.0001 현재 레짐 🟢 매수적기

01핵심 사상 — 문제를 둘로 쪼갠다

"지금 사야 하나"와 "무엇을 사야 하나"는 다른 질문이고, 다른 데이터·다른 검증이 필요하다. 레짐(타이밍)은 스크리너(선택) 위의 게이트 층으로 결합된다.

직교성의 실증 — 결합 검증 결과, 저평가 시그널의 절대수익은 레짐에 의존 (🟢 진입 +13.1% vs 🔴 진입 +7.6%/12개월)하지만, 그룹 대비 초과수익은 레짐과 무관(~7%p로 일정). "언제"와 "무엇을"은 실제로 분리 가능한 문제다.

02문제 1 — 매수 타이밍 레짐

시장 레벨 변수의 z-score 동일가중 합산 → 연속점수 → 과거 분위(q30/q70)로 🟢 매수적기 / 🟡 중립 / 🔴 보류 3단계. 명세: docs/regime_spec_v1.md

판정 규칙

score(t) = mean( z_i(t) )        # rolling 120개월 z, 발표지연 반영(M2 2개월·부동산원 1개월)
하드룰   : 기준금리 12개월 변화 > +1.0%p → 다른 변수 무관 강제 🔴
신호등   : score ≥ q70 → 🟢  ·  q30~q70 → 🟡  ·  ≤ q30 → 🔴   (expanding 분위, 미래 미사용)
장기 검증 (2003~2026, 사이클 3개) — 🟢 판정 월 이후 12개월 지수수익 평균 +6.2%·양(+)비율 97.1% vs 🔴 판정 월 −2.9%·46.7%. 격차 +9.1%p, 순열검정 p<0.0001. 변수는 "검증 무효 시 탈락" 조건부 채택 — M2가 실제로 탈락한 첫 사례.

스크리너 결합 (게이트)

신호등은 상시 표시. "레짐 연동" 토글 시 저평가 판정 임계를 레짐별로 조절: 🟢 −1.0σ · 🟡 −1.5σ · 🔴 −2.0σ — 보류 국면일수록 극단적 저평가만 통과시킨다. 스크리너 잠금(정보 차단)은 설계상 금지.

03문제 2 — 저평가 선택 엔진

"원래 그룹보다 20% 비싸던 단지가 지금 8%만 비싸다"를 저평가로 정의한다 — 절대 수준 비교가 아니라 평소 위상 대비 이탈. 명세: docs/algo_spec_v1.md

04검증 인프라 — 이 시스템의 존재 이유

"5년 상승장에선 아무거나 사도 올랐다"를 걸러내는 것이 백테스트의 목적. 벤치마크는 시장이 아니라 소속 그룹이다.

Event Study (선택 엔진)

시그널 +1개월 진입(신고지연) → 12/24/36개월 보유 → 그룹 중위 대비 초과수익. 순열검정으로 무작위 선택 대비 우위 판정. 취득·중개·보유세 단순 비용 모델 토글.

팩터 IC 분석

월별 크로스섹션 Spearman(팩터값 ↔ 이후 초과수익), Fama-MacBeth 평균. "이 변수가 적합한가"에 대한 정량 답변 장치.

레짐 장기검증

지수 레벨 2003~(사이클 3개: 2008 급락·2010–13 침체·2015–21 상승·2022 급락)에서 레짐 규칙 검증 → 통과한 규칙만 5년 단지 데이터에 결합.

진단 리포트

거래 희소성·조인율·분포·해제율·커버리지 5종 실측 — 파라미터를 감이 아니라 데이터로 확정. scoring/diagnostics.py

05설계 원칙

  • 검증 없이 채택 없다 — 모든 변수는 IC/장기검증을 통과해야 점수에 들어간다. 통과 못 하면 탈락(M2), 역효과면 중립화(모멘텀 가드).
  • 과적합 방어 우선 — 최적화 파라미터 4개 제한, 가중치 동일가중 고정, 표본 밖 검증(WFV)만 신뢰.
  • 누수 방지 — 신고지연 +1개월 진입, 발표지연 시차 반영, z-score는 shift(1), 분위는 expanding.
  • 교체 가능한 경계 — 그룹 정의·레짐 변수·비용 모델은 각각 단일 지점에서 교체 가능.
  • 예산 정보 무저장 — 현금·자산 입력은 세션 한정, 어떤 파일·DB에도 기록하지 않는다 (불변 원칙).
  • 정보 차단 금지 — 레짐이 나빠도 스크리너는 잠그지 않는다. 도구는 판단을 돕지, 대신하지 않는다.
