1프로젝트 개요

2024.09 ~ 2026.06 약 21개월치 카카오톡 리딩 채팅 원문(chathistory.txt, ~9만 라인 / 10MB)과 유튜브 강의 자막을 기반으로, 두 자문역의 투자 판단 방식 자체를 학습한 AI 에이전트를 구축하는 프로젝트입니다. 기존 YJ-Quant 대시보드(v9.3)에 통합하는 것을 최종 목표로 하며, 향후 v9.4 트랙으로 단일 앱화를 고려합니다.

  • 각 기법별 상세 카드(진입·청산 조건, 코딩 가능성, v9.3 백테스트 결합 포인트) 신설.

참고문서는 오재승 자문역 저작(네이버 카페 퀀텀리서치 / 유튜브 @oteam). 개인 내부 학습용으로만 사용.

확정된 프로젝트 범위 (사용자 피드백 기반)

  • 외부 서비스 아님 — 본인 개인 내부 사용 전용. → 법적/저작권 리스크 해소.
  • 정량 예측·대응력은 v9.3에서 이미 검증 완료. 따라서 적중률 검증은 "예측엔진 신설"이 아니라 자문역 발언 신뢰도 태깅(보조)으로 격하.
  • 시황 해설 = 보조 기능 (오재승식 아침 시황). RAG(과거 어투/관점) + 실시간 시세 결합.
  • ★ 개별기업 분석 = 메인 산출물. v9.3엔 빈규리식 상세 기업분석이 전무 → 이게 핵심 신규 기능.

2핵심 전략 — 페르소나 증류

★ 결정적 전환: 두 자문역이 약 6개월 뒤(~2026-12) 활동 종료 예정. → 프로젝트 본질이 "발언 검색·해설"에서 "두 사람의 가치관·판단기준을 if-then 룰북으로 증류 → 떠난 뒤 신규종목·미래시황에 이식하는 페르소나 엔진"으로 격상. 원본 소스가 더는 안 늘어남.

남은 6개월 = 데이터 보강 + 페르소나 '검증 완료' 굳히는 마지막 창. 1순위 KPI 재정의: "시장 적중"이 아니라 "에이전트가 자문역 본인을 얼마나 정확히 모사하나(모사 정확도)" — 에이전트 출력 vs 실제 자문역 당일 발언 대조로 룰북 보정. 은퇴 후엔 대조 불가.

핵심 설계 원칙

파인튜닝 ✗, RAG(청킹→임베딩→로컬 벡터DB→근거 인용) + 정량 룰 코딩이 정답. 두 자문역의 스타일이 정반대라 처리 방식도 다릅니다:

자문역룰 성격코딩 가능성처리 방식
오재승 정량 매매 룰 (MA / MACD / CCI / RSI) 코딩 가능 v9.3 백테스트 엔진에 즉시 결합 가능
빈규리 정성 펀더멘탈 룰 (해자·진위판별) 13중 2개만 코딩 나머지 11룰은 Claude LLM이 종목 맥락 읽고 판정

두 룰북을 합치면 "좋은 회사인가(빈규리) × 지금이 자리인가(오재승)" 완성 프레임이 됩니다.

5빈규리 룰북 (BKR-*, 13룰)

빈규리가 분석한 4개 종목(헥토파이낸셜·와이제이링크·켄코아에어로스페이스·엔젤로보틱스) 전문을 정독해 반복되는 판단 기준을 13개 if-then 룰로 증류했습니다. 파일: binkyuri_rulebook.json (v0.1).

철학

  • 재무구조가 탄탄하면서 성장성·비전이 있는 기업을 발굴한다.
  • 테마 편승이 아니라 실질 수혜·독점 포지션을 가려낸다 — '단순 테마주는 절대 아니다'.
  • 분석은 항상 정해진 순서: 사업 → 시장/촉매 → 해자 → 재무 → 리스크 → 결론.
  • 출력은 매수 추천이 아닌 '종목 소개'로 한정(디스클레이머 고정).

6오재승 룰북 (OJS-*, 7룰 · 기법 5종)

철학: 자산 = 가격 × 수량, 하락 = 매수기회, 레버리지는 정배열에만. 무릎·어깨/그물망 색전환/만수르 분할은 전부 정량 코딩 가능 → v9.3 백테스트 즉시 결합. ★ OJS-LINE-01·OJS-LEAD-01은 빈규리 밸류(BKR-*)와 직접 맞물림 — "좋은 회사(빈규리) × 싼 자리·타이밍(오재승)" 결합의 접점.

기법 상세 — 참고문서 5종 증류

① 만수르 기법 — KODEX 레버리지 · 지수/섹터 ETF (refDoc #1)

대상: KODEX 레버리지 등 지수·섹터 ETF 우선(모든 매매 적용 가능하되 빠지는 진폭은 종목별로 조정).

  • 매수 = 피라미딩 5분할(마틴게일). 역배열 초입~중반엔 매수 자제 → 안전마진을 형성하는 역배열 가격이 오면 시작.
  • 첫 매수 후 −10%마다 2배씩 매수(코덱스 레버리지 기준). 빠지는 진폭은 역사적 변동성 참조해 종목별 차등.
  • 5분할이 다 오기 전 반등이 잦음 → 그때는 역배열→정배열 초입의 차트 매수신호(또는 티레이더 '햇빛')에서 추가매수.
  • 매도: 지수 차트 매도신호 OR MFI/RSI 과열 신호에서 분할 매도.

키 포인트 3: ①빠지는 진폭 설정 ②빠질 때 2배씩 ③정배열 전환 후 차트 신호에서 추가매수. 코딩: 분할 스텝·금액 로직은 코딩 가능. '정배열 매수신호'는 OJS-NET-01(그물망)·MA 정배열로 정의 결합.

② 라인 트레이딩 — 밸류 라인 × MACD 트리거 (refDoc #2)

철학: "기술적 지표만으로 좋은 종목을 싸게 살 수 없다" → 펀더멘탈 밸류 라인 + 기술적 진입을 결합.

  • 라인 산정: 히스토리컬 PER 밴드 OR 연도별 영업이익 데이터로 절대적 저평가/고평가 가격대 사전 설정(미래가치는 영업이익 예상치·산업분석).
  • 매수(AND): 주가 < 저평가 라인 그리고 MACD 오실레이터 양선 전환.
  • 매도(AND): 주가 > 고평가 라인 그리고 MACD 오실레이터 음선 전환.
  • 차별점: 라인이 있어 물려도 저평가 구간에서 보유 기간 연장 가능. 저평가가 오래 방치되거나 고평가가 과열로 치닫는 시장 비효율을 포착(일반 가치투자 보완).

예시: 에스앤에스텍 — 저평가 ≤22,000 / 고평가 ≥50,000, 18,000원(2021.7) osc 양선전환에 매수. 코딩: MACD osc 전환은 코딩 가능, 밸류 라인은 빈규리/전문가 입력 → semi-auto. ★ 빈규리(BKR 밸류) × 오재승(타이밍) 결합의 교과서 사례.

③ 그물망 차트 — 12개 이동평균 리본 (refDoc #3) NEW

  • 설정: 20일 이동평균선 기준, 5일 간격, 12개 → 20·25·30…75일 MA 리본.
  • 색: 정배열=빨강, 역배열=파랑(대신증권 등 일부 HTS). 수렴=횡보, 발산=상/하 추세.
  • 정배열(빨강): 그물 안으로 복귀 후 재차 상단 돌파 시 추매 / 급락 시 그물망 하단에서 반등 노림.
  • 역배열(파랑): 빨강→파랑 전환 후 상단에서 계속 매도(주식=분할매도, 선물=매도 첫 진입). 색 바뀌는 첫 상/하단부터 반대 포지션.
  • ★ 바닥주 스킬: 파랑→빨강 전환 후 그물망 하단에서 첫 진입(반드시 색 전환 후) → 최바닥 매수 확률↑. 실증: 삼성전자·하이닉스·한미반도체.

코딩: 12개 MA 산출, 배열 순서(정·역배열), MA 간 표준편차(수렴·확산), 색 전환 첫 시점(first-flip) 모두 코딩 가능 → 만수르 '정배열 신호'의 정량 정의로 재사용.

④ 무릎어깨 MACD — 오실레이터 절댓값 첫 반전 (refDoc #5)

전제: 바닥·꼭지는 신기루지만 무릎·어깨는 연구로 승률을 높일 수 있다. 시총이 클수록 잘 통해 지수차트(코스닥·거래소·코스닥150)에 적용.

  • 도표화: 오실레이터가 0선 상향돌파→하향이탈 구간 / 하향이탈→상향돌파 구간별 수익률을 기록.
  • 표기: 양선 절댓값 vs 음선 절댓값 비교 → 큰 쪽이 상승/하락. 단, 상승·하락 자체에는 매매하지 않음.
  • 매매 = 절댓값의 첫 반전 이후 그 방향만: 첫 상승반전 후 → osc 음→양 전환에 매수만 / 첫 하락반전 후 → osc 양→음 전환에 매도만.
  • 백테스트: 코스닥 2022.1.5~2023.7.13 누적 +58%(저변동 지수 기준) → 인버스·곱버스·선물·옵션으로 레버리지 증폭 가능.

CCI·RSI로도 대체 가능(방법론이 핵심). 코딩: osc 0-cross 세그먼트화 + 절댓값 비교 + 첫반전 상태머신 → 코딩 가능. 현재 앱 OJS-MACD-01 자동 힌트의 정밀화 근거(기존 '양봉폭>음봉폭' 서술을 원문 로직으로 교체).

⑤ 주도주 발굴 — PSR × PER (refDoc #4) NEW

  • 10배 종목의 출발점: PSR 1배 미만 + 높은 PER. (PSR 저평가 + 강력한 산업성장 + 생산시설 확충=capex에 정답)
  • 제품 수명주기: 단일 제품은 R&D→성장가속→정점→사양. 연속 제품(쏘나타→그랜저→제네시스 합산매출)으로 성장 지속.
  • 매출-이익-주가: 적자구간(추가 R&D·경쟁사·일반관리비)이 존재. 주가는 기대감(IR)→실망감(손절)→새 기관·FOMO 순으로 매출·이익보다 먼저·크게 움직임.
  • 탄력성: 주가 > 영업이익 > 매출 (배트 비유 — 매출=손잡이, 영업이익=팔, 주가=배트 끝, 가장 큰 변화).

실증: 에코프로비엠 — 2020년 PSR 1.0·PER 19에서 출발, 매출 8,547억(’20)→92,155억(’23), 주가 10배+. 코딩: PSR<1 + PER 상위 + 매출 YoY 가속 + capex 증가 스크리너로 코딩 가능. ★ 빈규리 BKR-GROWTH/BKR-FIN과 상호보완(밸류·성장 더블 필터).

11Claude 정성 평가 엔진 상세

advisor_llm.py의 evaluate_qualitative_rules()가 핵심입니다. 안정적인 룰북+지시문은 system 프롬프트 앞단에 캐싱하고, 가변적인 종목 맥락만 user 뒤에 두어, 종목만 바뀌어도 캐시 prefix를 재사용합니다.

필드값
rule_id룰 ID (예: BKR-MOAT-01)
verdictmet / not_met / unknown
confidencehigh / medium / low (지식 불확실하면 낮춤)
