# 계산력 게임 (calculator_game) 설계

- 작성일: 2026-10-10
- 대상: 7살 어린이의 덧셈·뺄셈·구구단·나눗셈 계산력 훈련
- 벤치마크: 듀오링고 UI/UX

## 1. 목표와 단계

| 단계 | 내용 | 이번 범위 |
|---|---|---|
| 1단계 | 웹앱(PWA)으로 배포해 아이·가족 피드백 수집 | ✅ |
| 2단계 | 같은 코드를 Capacitor로 감싸 Android/iOS 출시 | ❌ (구조만 대비) |

**이번 범위에서 제외(YAGNI):** 계정·로그인, 서버, 클라우드 동기화, 다국어(한국어만), 광고·결제,
음성 읽어주기, 보상 수집(스티커 도감).

## 2. 기술 스택

- React 18 + TypeScript + Vite
- 상태: Zustand
- 애니메이션: Framer Motion
- PWA: vite-plugin-pwa (manifest + 서비스워커, 오프라인 플레이)
- 테스트: Vitest + @testing-library/react (jsdom)
- 효과음: Web Audio API 합성 (음원 파일 없음)
- 2단계 대비: 저장소 접근은 `core/storage.ts` 한 곳에만 둔다.

## 3. 화면

```
[프로필 선택] → [홈: 단계 맵] → [레슨 (10문제)] → [결과] → 맵
       └─ 🔒 [부모 설정] (어른용 문제로 잠금)
```

1. **프로필 선택** — 동물 이모지 아바타 + 이름 카드, "+ 추가" 카드. 프로필 여러 개 지원.
2. **홈(단계 맵)** — 유닛별 원형 노드가 세로 지그재그 경로로 배치.
   - 상태: 완료(금색 왕관) / 현재(통통 튀는 애니메이션) / 잠김(회색).
   - 상단 바: 🔥 스트릭, ⭐ XP·레벨, 🔊 소리 토글, ⚙️ 부모 설정.
3. **레슨** — 상단 진행 바, 하트 5개, 가운데 문제 + 마스코트, 하단 "확인" 버튼.
   확인 후 하단 피드백 시트: 정답(초록, "잘했어!") / 오답(빨강, 정답 표시 + 격려), "계속" 버튼.
4. **결과** — 마스코트 축하, 폭죽, 획득 XP, 정답률, 스트릭 상태, 왕관 진행.
5. **부모 설정** — 진입 시 어른용 곱셈 문제(두 자리 × 한 자리) 1개로 잠금.
   - 시작 단계 지정(그 앞 단계는 왕관 3개로 처리), 전체 잠금 해제 토글.
   - 타이머: 끔 / 10초 / 15초 / 20초.
   - 프로필 추가·삭제, 아이별 연산 정답률 요약.

### 비주얼

- 색: 초록 `#58CC02`(주요·정답), 하늘 `#1CB0F6`, 노랑 `#FFC800`(XP·왕관), 빨강 `#FF4B4B`(오답·하트),
  배경 흰색 / 연회색 `#F7F7F7`, 글자 `#3C3C3C`.
- 버튼: 모서리 16px, 아래쪽 4px 진한 테두리로 3D 느낌, 누르면 `translateY(4px)` + 테두리 제거.
- 폰트: Google Fonts `Jua`(한글 제목·숫자) + 시스템 폰트(본문).
- 터치 영역 최소 56px. 모바일 세로 우선, 최대 너비 480px 가운데 정렬.
- 마스코트: 자체 SVG "숫자 병아리", 표정 3종(기본·기쁨·격려).

## 4. 단계 맵

유닛 6개 × 단계 4개 = 24단계. 단계 ID는 `u{유닛}s{단계}` (예: `u1s1`).
각 단계는 레슨 3번 통과(왕관 3개)로 완료되며, 완료 시 다음 단계가 열린다.

| ID | 유닛 | 단계 | 규칙 |
|---|---|---|---|
| u1s1 | 10까지 덧셈 | 그림 세기 +1, +2 | a ∈ 1..8, b ∈ 1..2 |
| u1s2 | | 합 5까지 | a+b ≤ 5, a,b ≥ 1 |
| u1s3 | | 합 10까지 | a+b ≤ 10, a,b ≥ 1 |
| u1s4 | | 10 만들기 | a+b = 10 (빈칸 위주) |
| u2s1 | 10까지 뺄셈 | 그림 빼기 | a ∈ 2..6, b ∈ 1..2 |
| u2s2 | | 5 이내 | a ≤ 5, a−b ≥ 0 |
| u2s3 | | 10 이내 | a ≤ 10, a−b ≥ 0 |
| u2s4 | | 덧셈·뺄셈 섞기 | u1s3 + u2s3 |
| u3s1 | 20까지 | 받아올림 없는 덧셈 | a ∈ 10..19, 일의 자리 합 ≤ 9, 합 ≤ 19 |
| u3s2 | | 받아올림 덧셈 | a,b ∈ 2..9, a+b ∈ 11..18 |
| u3s3 | | 받아내림 뺄셈 | a ∈ 11..18, b ∈ 2..9, a의 일의 자리 < b |
| u3s4 | | 섞기 | u3s1 + u3s2 + u3s3 |
| u4s1 | 구구단 ① | 2단 | 2 × (1..9) |
| u4s2 | | 5단 | 5 × (1..9) |
| u4s3 | | 3단 | 3 × (1..9) |
| u4s4 | | 4단 | 4 × (1..9) |
| u5s1 | 구구단 ② | 6단 | 6 × (1..9) |
| u5s2 | | 7단 | 7 × (1..9) |
| u5s3 | | 8·9단 | {8,9} × (1..9) |
| u5s4 | | 전체 섞기 | (2..9) × (1..9) |
| u6s1 | 나눗셈 | 2·5단 나누기 | (d×q) ÷ d, d ∈ {2,5}, q ∈ 1..9 |
| u6s2 | | 3·4단 | d ∈ {3,4} |
| u6s3 | | 6~9단 | d ∈ 6..9 |
| u6s4 | | 곱셈·나눗셈 섞기 | u5s4 + (d ∈ 2..9 나눗셈) |

- 뺄셈 결과는 항상 0 이상, 나눗셈은 항상 나누어떨어진다.
- 나눗셈 문제 첫 등장 시 힌트 문구: "구구단 거꾸로! 3 × ? = 12".

## 5. 문제 생성

- 단계는 규칙 데이터(`StageDef`)로 정의하고, 문제는 매번 시드 랜덤(`mulberry32`)으로 생성.
- 레슨 = 10문제. 같은 수식이 연속 2번 나오지 않는다(레슨 내 중복은 가능한 한 회피).
- 문제 유형:
  - `choice` — 객관식 4지선다
  - `keypad` — 숫자 키패드 입력
  - `blank` — 빈칸 채우기 (예: `3 + □ = 7`, 키패드로 입력)
  - `picture` — 이모지 그림 세기 + 객관식 (유닛 1~2의 덧셈·뺄셈만)
- 유형 비율 (해당 단계의 현재 왕관 수 기준):

| 왕관 | choice/picture | keypad | blank |
|---|---|---|---|
| 0 | 70% | 20% | 10% |
| 1 | 40% | 40% | 20% |
| 2+ | 20% | 50% | 30% |

  picture를 허용하는 단계에서는 choice 몫의 절반을 picture로 쓴다. u1s1, u2s1은 picture를 우선(choice 몫 전부).
- 객관식 오답 보기: 정답 ±1, ±2, 연산 혼동값(덧셈↔뺄셈, 곱셈 이웃 단 값) 후보에서 0 이상·정답과 다른 값 3개.
  보기 4개는 서로 다르고 섞어서 제시.
- 오답 복습: 틀린 문제는 레슨 끝에 한 번 더 출제(복습 문제는 진행 바·점수에 포함하지 않고 1회만).

## 6. 게임 규칙

- **XP**: 정답 +10, 레슨 완료 +20, 무실수(복습 제외 첫 시도 전부 정답) +10.
- **레벨**: 레벨 n → n+1 필요 누적 XP = 50·n·(n+1) → 100, 300, 600, … (레벨 1에서 시작).
  레벨업 시 결과 화면에서 축하 연출.
- **하트**: 레슨마다 5개, 첫 시도 오답 시 −1. 0이 되어도 게임오버 없음 — "잠깐 쉬어가자!" 후 계속 진행.
- **레슨 통과**: 첫 시도 정답률 ≥ 70% **그리고** 레슨 종료 시 하트 > 0.
  통과 시 해당 단계 왕관 +1 (최대 3). 미통과여도 레슨 완료 XP·스트릭은 인정.
- **단계 잠금**: 첫 단계는 열려 있음. 이전 단계 왕관 3개면 다음 단계 열림. `unlockAll`이면 전부 열림.
- **스트릭**: 로컬 날짜(YYYY-MM-DD) 기준, 하루 1레슨 이상 완료 시 유지.
  - 같은 날 재플레이: 변화 없음. 어제 플레이: +1. 정확히 하루 거름 + 이번 ISO 주에 얼리기 미사용: 얼리기 사용, +1.
  - 그 외: 1로 리셋.
- **타이머**(기본 끔): 시간 초과 시 정답을 보여주고 넘어간다. 하트는 깎지 않지만,
  정답률에서는 "맞히지 못함"으로 세고 오답 복습에도 넣는다.
- **마스코트**: 정답 → 기쁨, 오답 → 격려, 3연속 정답 → "불붙었다!" 말풍선.
- **효과음**: 정답 "딩동", 오답 "뿅", 레슨 완료 팡파르. 소리 토글 저장. 오답 시 `navigator.vibrate(80)` (지원 시).

## 7. 데이터 저장

`localStorage` 키 `calculator_game:v1`에 JSON 저장.

```ts
interface AppData {
  schemaVersion: 1;
  profiles: Profile[];
  activeProfileId: string | null;
  settings: { soundOn: boolean; timerSec: number | null };
}
interface Profile {
  id: string; name: string; avatar: string;   // avatar = 동물 이모지
  xp: number;                                  // 레벨은 xp로 계산
  streak: { count: number; lastPlayedDate: string | null; freezeUsedWeek: string | null };
  stages: Record<string, { crowns: number; bestAccuracy: number }>;
  unlockAll: boolean;
  stats: Record<'add' | 'sub' | 'mul' | 'div', { correct: number; total: number }>;
}
```

- 읽기 실패·JSON 손상·스키마 불일치 → 기본값으로 시작하고 `loadError` 플래그를 세워 부모 설정에 안내 문구 표시.
- 쓰기 실패(용량·사생활 보호 모드) → 예외를 삼키고 앱은 계속 동작.
- `schemaVersion`으로 향후 마이그레이션.

## 9. 테스트

- `core` 단위 테스트(Vitest):
  - generator: 24개 단계 각각 1000문제 생성 → 규칙 준수, 보기 4개 서로 다름·정답 포함·음수 없음, 시드 재현성.
  - scoring: XP 합산, 레벨 경계(99/100/299/300), 통과 기준 경계(69%/70%, 하트 0), 왕관 상한, 잠금 판정.
  - streak: 같은 날, 연속, 하루 거름(얼리기 사용/이미 사용), 이틀 이상 거름, ISO 주 경계.
  - storage: 저장→불러오기 왕복, 손상 JSON, 스키마 불일치, setItem 예외.
- UI 테스트(Testing Library): 레슨 1판 끝까지 진행해 결과 화면 도달, 부모 잠금 통과/거부.
- 수동: 모바일 뷰포트에서 터치 크기·애니메이션·소리 확인.

## 10. 배포

- `npm run build` 결과물(정적 파일)을 GitHub Pages 또는 Vercel에 배포 — 실제 배포는 구현 후 사용자 확인을 받고 진행.
- 2단계(범위 밖): Capacitor 빌드, `storage.ts`를 Capacitor Preferences로 교체, 아동용 개인정보 정책, 스토어 에셋.
