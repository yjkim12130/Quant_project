3EV 독식 점수 (0~100)

당첨 확률과 무관하게, 당첨됐을 때 다른 당첨자와 나눠 가질 리스크만 점수화한다. 가중치는 전 회차 실증 데이터에서 유의했던 신호만 반영:

score = 연속수포함×30 + round((6 − 생일범위개수)/6×30) + 40번대포함×20 + 합계비인기구간×20
요소배점실증 근거 (1~1,236회)
연속수(예: 21,22) 포함+30유일한 통계적 유의 신호 — 연속수 조합은 1등 당첨자 수가 유의하게 적음 (Spearman ρ=−0.089, p=0.004)
생일범위(≤31) 비중 낮음최대 +30전부 31 이하인 회차의 당첨자 1.07배 vs 3개 이하 0.95배 (~12% 차이)
40번대(≥40) 포함+20생일 기반 수동 선택에서 소외되는 구간
번호 합계가 100~170 밖+20수동 선택 합계가 몰리는 인기 구간 회피

4EV 조합 생성기

균등 랜덤 6개 추출 → 중복 조합 제거 → EV 점수 계산 → min_score 미달 기각 → n게임 채우면 종료

생성 자체가 순수 균등 랜덤(rejection sampling)이므로 어떤 조합이 나와도 당첨 확률은 동일하다. 필터는 확률이 아니라 "겹칠 사람 수"만 바꾼다. 최대 시도 횟수(20,000회) 초과 시 찾은 만큼만 반환.

5예측 실험실 알고리즘 (7종)

모든 알고리즘은 예측 시점 이전 데이터만으로 번호별 점수를 만들고 상위 6개를 출력한다.

① 콜드 (장기미출현)
score(n) = 번호 n이 마지막으로 나온 뒤 지난 회차 수(gap). 오래 안 나온 순 top6.
② 핫넘버 (윈도우 빈도)
score(n) = 최근 W회 출현 횟수. W ∈ {10, 26, 52, 104} 로 튜닝. 전체 회차 빈도 버전도 별도 후보.
③ EWMA (지수가중 빈도)
e(n) ← (1−α)·e(n) + α·1{n 출현}, α ∈ {0.02, 0.05, 0.1} 최근 회차일수록 가중치를 크게 주는 빈도. α가 클수록 단기 반응형.
④ 동시출현 마르코프
전이행렬 C[m][n] = "m이 t−1회차에 나왔을 때 n이 t회차에 나온 횟수" (라플라스 스무딩 +1). 직전 회차 6개 번호 m 각각에 대해 P(n|m)을 평균한 값이 score(n).
⑤ 종합점수 (2단계)
score(n) = z(최근52 빈도) + z(gap) + z(동시출현). 각 신호를 표준화(z-score) 후 합산 — "후보군 확률 계산 → top-N 추출"이라는 사용자 제안 방식의 구현.
⑥ ML (RandomForest)
번호별 이진 분류: "다음 회차에 나올까?" 특징 10개(윈도우 빈도 4종, 전체 빈도, gap, EWMA 3종, 동시출현). 학습 표본 = 과거 회차 × 45개 번호. 100트리·깊이 6, 20회차마다 재학습(walk-forward). 출현 확률 top6.
⑦ 랜덤 (기준선)
회차당 균등 랜덤 100장 시뮬레이션 평균. 모든 알고리즘이 이겨야 하는 기준.

6검증 프로토콜 — 과적합 방지 설계

Validation 600~936회
12개 후보 전부 평가·튜닝 → 1위 1개만 선정 → Test 937~1,236회
승자만 단 한 번 평가 → Bonferroni ×12 보정
  • 선정과 검증을 분리: "여러 개 돌려서 최고를 고르면 노이즈에 과적합된 운을 고른다"를 차단
  • 귀무가설: 평균 적중 = 0.800개 (초기하분포, 분산 0.6145). 단측 정규근사 검정

판정: validation 1위(+9%로 보였던 콜드)가 test에서 랜덤 이하로 추락 (보정 p=1.000). 번호별 출현빈도 자체도 균등분포와 구분 불가(카이제곱 p=0.957). "직전 회차 번호는 연속으로 안 나온다"는 속설도 기각 — 61.3% 회차에서 1개 이상 재출현.

결론: 과거 데이터에 예측력은 없다. 예측 실험실 탭은 이 판정을 화면에 함께 표시한 채 재미용으로 제공하며, 실질적 우위는 EV 독식 점수(3장)에서만 나온다.
