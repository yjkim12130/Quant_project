YJ-Content Factory

부부 크리에이터 윤진 + 영준을 위한 콘텐츠 자동화 시스템. 정해진 포맷의 Input만 넣으면 블로그 · 인스타 · 유튜브 콘텐츠가 자동 생성되고, 최종적으로는 AI 영상 생성(Vix)까지 연결되는 파이프라인.

개발 도구 · Claude Code (CLI) 개발 · 영준 사용 · 윤진(콘텐츠) · 영준(콘텐츠+개발) 최종 수정 · 2026-05-29
01

프로젝트 개요

콘텐츠 제작의 반복 작업을 자동화하여 부부의 시간을 절약하고, 영상 자산을 체계적으로 축적하는 것을 목표로 한다.

핵심 비전

정해진 포맷의 Input만 넣으면, 블로그 · 인스타 · 유튜브 콘텐츠가 자동 생성되는 프로그램. 최종적으로는 만들어진 산출물을 기반으로 Vix(AI 영상 생성 툴)를 연동해 영상까지 자동 생성한다.

제작 주체

  • 윤진 — 콘텐츠 제작 (요리 + 육아)
  • 영준 — 콘텐츠 제작 + 시스템 개발 (재테크/투자)

산출 대상 플랫폼

네이버 블로그 Instagram (릴스·캐러셀·스토리) YouTube (쇼츠·롱폼) → Vix 영상 (Phase 3)

영준 채널 특이사항 — 퀀트앱 연동

영준은 이미 퀀트 앱 YJ-Quant (Streamlit 기반)를 운영 중이며, 매일 "오늘의 지침"(어떤 종목을 어떤 비율로 매수/매도할지)이 텍스트 + 화면 캡처 형태로 나온다. 이 지침 데이터를 그대로 Input으로 넣으면 콘텐츠가 자동 생성되어야 한다.

⚠️ 필수 규칙 — 투자 콘텐츠의 모든 Output에는 "투자 권유가 아닙니다" 면책 조항이 자동 삽입되어야 한다.

부부 시너지 (향후)

윤진 요리 × 영준 재테크 콜라보 콘텐츠 — 예: "월 식비 30만원 집밥 챌린지"

03

윤진 파이프라인

촬영 전(가이드 생성)과 촬영 후(콘텐츠 생성)로 나뉘는 2단계 워크플로우. 두 단계는 레시피 데이터로 자동 연결된다.

PHASE A · 촬영 전

"어떻게 찍을지" 가이드 생성 — 영상이 없는 상태에서 텍스트만으로 생성. 윤진이 태블릿/프린트로 보고 촬영.

INPUT · 텍스트
  • 요리명
  • 재료 + 양
  • 조리 과정 (순서)
  • 꿀팁 / 실패 포인트
  • 비하인드 에피소드
  • 목표 러닝타임 (30·60·90초)
→
처리 · Claude
  • 채널 프로필 + Input 조립
  • 촬영 가이드 생성
→
OUTPUT · 촬영 가이드
  • A1 영상 시나리오
  • A2 촬영 대본
  • A3 구도/앵글 가이드
  • A4 차별화 포인트
  • A5 촬영 체크리스트
A1
영상 시나리오전체 영상 구조 · 타임라인 · 후킹 문장 · BGM 분위기
A2
촬영 대본타임코드별 멘트 · 액션 지시 · 표정 가이드
A3
촬영 구도/앵글 가이드장면별 삼각대 위치·높이·각도 · 앵글(탑뷰/45도/정면/클로즈업) · 조명 팁 · 카메라 이동 타이밍 · 흔한 실수 경고 · 반드시 찍어야 할 장면 TOP 5 · 완성 비주얼 샷
A4
차별화 포인트경쟁 채널 대비 차별점 · 시리즈화 가능성
A5
촬영 체크리스트요리 전 · 장비 · 촬영 중 · 놓치면 안 되는 것 · 촬영 후 체크
↓  윤진이가 가이드를 보고 촬영  ↓
PHASE B · 촬영 후

찍은 영상으로 멀티 플랫폼 콘텐츠 생성. Phase A의 레시피 데이터가 자동 연결됨.

INPUT
  • 촬영 영상 (.mp4)
  • Phase A 레시피 (자동 연결)
  • (선택) 촬영 중 변경 메모
  • (선택) 완성 요리 사진
→
처리 · 영상 분석
  • Whisper STT 자막 추출
  • FFmpeg/OpenCV 키프레임·썸네일
  • 장면 전환 감지
→
OUTPUT · 멀티 플랫폼
  • B1 편집 가이드
  • B2 인스타그램 패키지
  • B3 네이버 블로그 글
  • B4 유튜브 패키지
  • B5 수익화 연결
B1
편집 가이드삭제 구간(타임코드+이유) · 배속 구간 · 슬로우모션 · 자막(타임코드+텍스트) · 텍스트 오버레이 · BGM 전환 · 효과음 · 예상 길이
B2
인스타그램 패키지릴스 캡션+해시태그 · 캐러셀 5~7장 텍스트 · 스토리 문구 · 썸네일 추천
B3
네이버 블로그 글SEO 제목 · 본문(서론-재료표-과정-팁-마무리) · 사진 위치 · 태그
B4
유튜브 패키지쇼츠 제목+설명+태그 · 롱폼 챕터 구성
B5
수익화 연결쿠팡파트너스 추천 상품 · 협찬 가능 카테고리 · 시리즈화 가능성

육아 콘텐츠

  • 레시피 카드 대신 "에피소드 카드" Input 사용 (에피소드 제목 · 아이 나이 · 상황 · 교훈/팁 · 감정 흐름 등)
  • Phase A/B 구조는 동일하되, Input 포맷만 다름
04

영준 파이프라인

퀀트앱 "오늘의 지침" 데이터를 Input으로 받아 5종 콘텐츠를 생성한다. 재테크/절세 콘텐츠도 동일한 Output 구조를 사용한다.

퀀트 지침 → 콘텐츠

YJ-Quant 앱의 일일 매매 지침(JSON) + 화면 캡처를 입력받아 자동 변환.

INPUT
  • 오늘의 지침 (JSON): 날짜·시장요약·전략명·매매시그널(종목+비율+근거)·리스크·핵심지표(VIX, F&G)
  • 퀀트앱 화면 캡처 (대시보드·레이더 차트)
  • (선택) 영준 코멘트
  • (선택) 시장 이슈 키워드
→
처리 · Claude
  • 지침 JSON 파싱
  • 면책 조항 자동 삽입
  • 5종 콘텐츠 생성
→
OUTPUT
  • E1 유튜브 영상 대본
  • E2 영상 구성/설계 전략
  • E3 인스타 캐러셀
  • E4 블로그 분석 글
  • E5 쇼츠/릴스 스크립트
E1
유튜브 영상 대본오프닝 후킹 · 시장 상황 · 전략 해설 · 근거 · 리스크 경고 · CTA
E2
영상 구성/설계 전략화면 구조 · 차트 배치 · 자막 스타일 · 참고 영상 스타일
E3
인스타 캐러셀5~7장 슬라이드 텍스트 · 후킹 표지 · 캡션+해시태그
E4
블로그 분석 글시장 분석 · 전략 설명 · 차트 삽입 위치 · 면책 조항 · SEO 태그
E5
쇼츠/릴스 스크립트60초 이내 대본

재테크 / 절세 콘텐츠

  • 별도 Input 포맷: 주제 · 핵심 포인트 · 타깃 · 참고 링크 · 영준 경험담
  • Output은 E1~E5와 동일 구조

06

개발 로드맵

텍스트 가이드 MVP → 영상 분석 → AI 영상 생성 → 완전 자동화의 4단계 진화.

Phase 1 — MVP2주텍스트 Input → 촬영 전 가이드
  • 윤진 Phase A (레시피 → 시나리오+대본+구도+차별화+체크리스트)
  • 영준 기본 (퀀트 지침 → 유튜브 대본+영상 전략)
  • Streamlit 2탭 UI
Phase 2 — 영상 분석 + 멀티 플랫폼3주
  • 윤진 Phase B (영상 분석 → 편집 가이드+인스타+블로그+유튜브)
  • 영준 확장 (인스타 캐러셀+블로그+쇼츠)
  • 육아 콘텐츠 에피소드 카드 추가
Phase 3 — Vix 영상 자동 생성4주
  • 산출물(대본+구도+자막+이미지) → Vix API → 완성 영상(.mp4) 자동 생성
  • 직접 촬영 vs AI 생성 하이브리드 전략
Phase 4 — 완전 자동화 + 시너지장기
  • 인스타/유튜브 성과 데이터 연동 → 프롬프트 자동 최적화
  • 부부 콜라보 콘텐츠 자동 제안
  • 예약 발행 API 연동
