## 안건 A. 동일자산군(Peer Group) 정의 — ★가장 중요한 결정

> ✅ **확정 (2026-08-14)**: **A4 계층 하이브리드**
> - 그룹키 = (법정동, 면적밴드 3구간 [~60/60~85/85~], 연식밴드 3구간 [~10년/10~25년/25년~, 현재 기준 경과년수 동적 계산])
> - 그룹 내 단지 5개 미만 → (시군구, 면적밴드, 연식밴드)로 폴백 → 그래도 미달 시 스코어링 제외
> - `make_group_key()` 함수로 분리, Phase 5에서 학군·역세권 축으로 교체 가능하게 설계
> - 최소 표본 기준(5개)은 적재 후 체크리스트 1번 실측으로 재검토

주식은 "같은 섹터 ETF"로 그룹이 자명하지만, 아파트는 그룹 정의 자체가 알고리즘의 절반이다.
괴리율은 "그룹 평균 대비"로 계산되므로, 그룹이 잘못되면 이후 모든 게 무의미.

| 옵션 | 정의 | 장점 | 단점 |
|---|---|---|---|
| A1 | 법정동 단위 | 데이터만으로 즉시 가능 | 동 경계≠생활권 (예: 같은 동인데 학군 다름) |
| A2 | 학군+역세권 그룹 | 계획서 원안, 실수요 논리에 부합 | 좌표 없음 → 지오코딩 필요, 학교알리미 파싱 필요, Phase 5까지 지연 |
| A3 | 특성 유사도 매칭 (연식밴드×면적대×세대수 k-NN) | 헤도닉 논리, 자동화 가능 | 지역 프리미엄을 놓침 (수원 단지와 강남 단지가 같은 그룹 될 수 있음) |
| A4 | 계층 하이브리드: (시군구 or 동) × 면적대 × 연식밴드 | 즉시 가능 + 지역 통제 | 그룹당 표본 수 부족 위험 |

★ 잠정 의견: **v1은 A4로 시작** (동 단위 × 전용면적 3구간[~60/60~85/85~] × 연식 3구간[~10년/10~25년/25년~]), 그룹당 최소 단지 수 미달 시 시군구 단위로 폴백. A2(학군·역세권)는 데이터 파이프라인이 갖춰지는 Phase 5에서 그룹 정의를 업그레이드하는 로드맵. **그룹 정의를 교체 가능한 인터페이스로 설계**해두는 게 핵심 (YJalgo에서 자산군 리스트만 바꾸면 되는 구조와 동일).

논의 포인트: 연식 구간 경계(재건축 기대 시작점 25년? 30년?), 그룹 최소 표본 기준(단지 5개? 거래 20건?).

## 안건 B. 가격 정규화 — 희소 거래 문제

> ✅ **확정 (2026-08-14)**:
> - 가격 단위: 단지×면적밴드별 **월 중위 ㎡당가**
> - 결측 처리: **3개월 롤링 중위 + 마지막 관측 이월 최대 6개월**, 초과 시 해당 월 스코어링 제외 (적재 후 체크리스트 1번으로 윈도 재검토)
> - 층 보정: **v1 스킵**
> - 해제거래: **지표에서 제외 + 최근 1년 해제비율 높은 단지 ⚠️ 경고 플래그**

주식과 결정적 차이: 주식은 매일 종가가 있지만, 아파트는 **단지×면적대별 월 거래가 0~수 건**.
YJalgo의 시계열 로직을 직역하면 결측투성이가 된다.

- B1. 기본 단위: 단지×면적대별 **월 중위 평당가** (㎡당 만원). 평균 아닌 중위(저층/특수거래 왜곡 방어)
- B2. 결측 처리: 3개월(or 6개월) 롤링 중위값으로 스무딩 + 마지막 관측 이월(limit 설정) — 이월 한도 초과 시 그 단지는 해당 월 스코어링 제외
- B3. 층 효과: v1은 무시(중위값으로 완화) vs 층수 구간별 보정계수 vs 헤도닉 회귀
- B4. 해제거래(`cancelled=1`): 지표 계산에서 제외하되, **해제 비율 자체를 이상신호로 활용** 가능(자전거래 의심 단지 플래그)

★ 잠정 의견: B1+B2(3개월 롤링, 이월 6개월 한도)+B4 제외. 층 보정은 v1 스킵 — 중위값+동일 면적대 비교로 상당 부분 통제됨. 데이터 적재 후 "단지별 월 거래건수 분포"를 보고 롤링 윈도를 확정.

## 안건 C. Factor1 괴리율 정의 — analyze_rv의 부동산 번역

> ✅ **확정 (2026-08-14)**: **C3 — ratio(t) = 단지 ㎡당가 / 그룹 중위 ㎡당가의 자기 역사 대비 z-score**
> lookback·임계값(σ)은 그리드서치+WFV 대상 파라미터로 이연. 절대 ±5% 임계는 사용 안 함.

YJalgo 원형: 그룹 종목들을 기간 시작점=100으로 정규화 → 그룹 평균 대비 현재 괴리율, ±5% 판정.

- C1 (직역): 시작점 정규화 후 그룹 평균 대비 % 괴리 — 시작 시점 선택에 민감, 부동산에선 시작점이 자의적
- C2 (수준 비교): 현재 평당가 / 그룹 중위 평당가 비율 — 단지 고유 프리미엄(브랜드·입지)을 저평가로 오판
- C3 (비율의 역사적 z-score): `ratio(t) = 단지 평당가 / 그룹 중위 평당가`의 **자기 역사 대비 z-score** — 페어트레이딩 로직. "원래 그룹보다 10% 비싸던 단지가 지금 5%만 비싸다 = 저평가"
- C4: C3 + 전고점 대비 DD 결합

★ 잠정 의견: **C3가 정답에 가장 가깝다.** 단지 고유 프리미엄을 자동 통제하고, YJalgo의 "동일군 대비 상대 저평가" 철학과 정확히 일치. lookback(2~3년?)과 z-score 임계(-1σ? -1.5σ?)는 데이터 분포 확인 후 그리드서치 대상. YJalgo의 ±5% 절대 임계는 부동산 분포에 안 맞을 가능성이 높아 σ 기반으로 전환 제안.

## 안건 D. Factor3 과열도/모멘텀 — analyze_oh의 부동산 번역

> ✅ **확정 (2026-08-14)**: **D1(전고점 대비 DD) + D2(12개월 모멘텀) 결합**만 v1 스코어에 포함.
> D3(거래량)·D4(전세가율 방향)는 백테스트에서 신호력 검증 후 편입 여부 결정.

MA50/200·RSI·볼린저는 일봉 전제라 직역 불가. 월 단위 재정의 필요:

- D1. 전고점 대비 조정폭(DD): 단지 평당가의 역사적 고점 대비 현재 % — "얼마나 빠졌나"
- D2. 12개월 모멘텀: 최근 12개월 평당가 변화율 — 추세 확인
- D3. 거래량 신호: 그룹 월 거래건수의 z-score — 바닥권 거래 급증 = 반등 신호 가설
- D4. 전세가율 방향: 매매가 하락 중 전세가 유지 → 전세가율 상승 = 바닥 신호 가설

★ 잠정 의견: D1+D2를 Factor3로 (YJalgo의 "매수구간" 개념 = DD 크고 모멘텀이 반전 초입). D3·D4는 백테스트에서 신호력이 확인되면 추가. **주의: 부동산 모멘텀은 주식과 달리 강한 양의 자기상관(추세 지속)** — "많이 빠진 것"이 계속 빠질 수 있어 D1 단독 사용은 위험, 반드시 D2와 결합.

## 안건 E. Factor2 전세가율 — 신호 방향 확정 필요

> ✅ **확정 (2026-08-14)**: **E2를 점수로**(자기 역사·그룹 대비 전세가율 상승 = 가점, C3 프레임 재사용) + **E3를 사이드바 옵션 필터로**(전세가율 하한 토글). E1 절대수준 점수화는 기각.

전세가율의 이중성: **높음** = 실수요 탄탄·하방 방어·갭 작음(매수 유리) vs **낮음** = 미래 기대 프리미엄(강남 재건축은 구조적으로 낮음).

- E1. 절대 수준을 점수화 (높을수록 가점)
- E2. **그룹 내 상대 + 자기 역사 대비**: 같은 그룹에서 전세가율이 역사적 평균보다 높아진 단지에 가점
- E3. 점수가 아닌 **하방 방어 필터**로만 사용 (예: 전세가율 50% 미만 제외)

★ 잠정 의견: E1은 지역 편향(외곽 고전세가율 단지만 상위 도배)이 확실해 반대. **E2를 점수로, E3을 옵션 필터로** 병행. 이것도 C3와 같은 "자기 역사 대비" 프레임이라 코드 재사용 가능.

## 안건 F. 팩터 결합 방식 — 과적합 방어가 핵심

> ✅ **확정 (2026-08-14)**: **F2+F3 계층 구조** — 하드필터(예산·전세가율 하한 옵션·유동성·해제 플래그) → 핵심 2팩터(C3 괴리율 z + D 과열도) 동일가중 랭킹 → 호재·세수 보너스(고정 규칙). 그리드서치+WFV 대상 파라미터는 3~4개로 제한.

YJalgo는 그리드서치+WFV로 파라미터를 최적화하지만, 부동산은 **월 단위 × 5년 = 시점 60개**뿐이라 표본이 압도적으로 적다. 가중치 6개를 그리드서치하면 확실히 과적합.

- F1. 6팩터 가중합 그리드서치 (YJalgo 직역) — 과적합 위험 大
- F2. **2계층: 하드필터(예산·전세가율·유동성) → 핵심 2팩터(C3 괴리율 + D 과열도) 동일가중 랭킹** — 파라미터 최소화
- F3. F2 + 호재/세수는 ±보너스 점수 (랭킹 미세조정용, 최적화 대상 아님)

★ 잠정 의견: **F2+F3.** 최적화는 "괴리율 z 임계, lookback, DD 임계" 3~4개 파라미터로 제한하고 WFV로 시점 분할 검증. 나머지 팩터는 고정 규칙. YJalgo에서도 파라미터 수를 줄인 버전이 WFV에서 더 견고했던 경험과 일치.

## 안건 G. 백테스트(event study) 설계

- G1. 신호 정의: "시점 t에 스코어 상위 N% (or z < 임계) 진입"
- G2. 성과 측정: t+1y/2y/3y 수익률. **벤치마크 = 소속 그룹 평균 수익률 대비 초과수익** (시장 전체 상승기 착시 제거 — YJalgo의 벤치마크 대비 알파와 동일 논리)
- G3. 누수 방지: 시점 t 스코어는 t 이전 데이터만 사용(신고 지연 고려 — 실거래 신고는 계약 후 30일 이내 → t-1개월까지만 사용이 안전)
- G4. 비용 모델: 취득세(1~3주택 구간)+중개보수+보유세 단순 모델, 양도세는 보유기간·1주택 비과세 가정 토글
- G5. 검증 통계: YJalgo의 순열검정(`_perm`) 이식 — "무작위 단지 선택 대비 초과수익이 유의한가"

★ 잠정 의견: G2의 그룹 대비 초과수익과 G5 순열검정이 이 프로젝트의 신뢰도를 결정. "5년 상승장에서 아무거나 사도 올랐다"를 걸러내는 게 백테스트의 존재 이유.

## 데이터 적재 후 즉시 확인할 가설 체크리스트 (Phase 1 완료 직후 실행)

브레인스토밍 결론 중 상당수는 아래 실측으로 확정해야 함:

1. **거래 희소성**: 단지×면적대별 월 거래건수 분포 → B2 롤링 윈도, A4 그룹 최소 표본 기준 확정
2. **단지명 정합성**: 같은 단지의 `complex_name` 표기 변형 비율 (매매 vs 전세 테이블 조인 성공률) → 정규화 규칙 필요 여부
3. **괴리율 분포**: C3 ratio z-score의 지역별 분포 (강남 vs 화성) → 임계값 σ 설정
4. **해제거래 비율**: 지역·시기별 `cancelled` 비율 → B4 이상신호 활용 가치 판단
5. **전세가율 계산 가능률**: 매매·전세 모두 있는 단지 비율 → Factor2 커버리지
