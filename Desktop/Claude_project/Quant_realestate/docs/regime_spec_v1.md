## 1. 출력 (R-A)

- 내부: 연속 레짐점수 `regime_score` (변수별 z 동일가중 합산)
- 표시: 🟢 매수적기 / 🟡 중립 / 🔴 보류 3단계 + 점수 병기
- 3분할 임계는 장기 검증(§4)에서 확정 (초안: 상/하위 30% 분위)

## 2. 변수 6개 (R-B, 조건부 — 장기 검증 무효 시 탈락)

| # | 변수 | 축 | 산출 | 소스 (검증 상태) |
|---|---|---|---|---|
| 1 | 기준금리 방향 | 유동성 | 12개월 변화 부호·크기 (인하=+) | ECOS `722Y001`/`0101000` ✅ |
| 2 | M2 증가율 | 유동성 | YoY %, 자기 역사 z (확장=+) | ECOS `161Y006`/`BBHA00` ✅ (2003-10~) |
| 3 | 시장 전세가율 방향 | 수급 | 30개 지역 집계 전세가율의 12개월 변화 (상승=+) | 자체 DB ✅ |
| 4 | 매매/전세 거래량 비율 | 수급 | 매매건수÷전세건수의 z (매매 회복=+) | 자체 DB ✅ |
| 5 | 지수 모멘텀·DD | 가격 | 수도권 지수 12개월 모멘텀 + 전고점 DD | R-ONE (키 발급 대기) |
| 6 | 매수우위지수 (심리) | 심리 | 자기 역사 z | R-ONE (키 발급 대기) |

- 후행성 주의: M2는 발표 ~2개월 지연 → 산출 시점 정렬(publication lag) 필수 (누수 방지)
- 변수 3·4는 5년치만 존재 → 장기 검증에서는 1·2·5·6만으로 코어 규칙 검증, 3·4는 결합 검증에서 기여도 확인

## 3. 판정 로직 (R-D)

```
regime_score(t) = Σ z_i(t) / n_valid      # 변수별 z 동일가중, 결측 변수는 분모에서 제외
하드룰 (초안, 장기 검증에서 확정):
  - 기준금리 12개월 변화 > +100bp (인상 가속) → 강제 🔴 보류
신호등: score > q70 → 🟢 / q30~q70 → 🟡 / < q30 → 🔴  (분위는 장기 표본 기준)
```

- 가중치 최적화 금지 (동일가중 고정) — 문제 2와 동일한 과적합 방어 원칙
- 하드룰은 최대 2개

## 4. 검증 (R-C, 이원 구조)

**4-1. 장기 검증 (지수 레벨, 2003~)**
- 데이터: R-ONE 수도권(또는 서울+경기) 매매가격지수 월간 × ECOS 금리·M2 × R-ONE 심리지수
- 방법: 매월 레짐 판정 → 이후 12/24개월 지수 수익률을 레짐별 비교
- 통과 기준: 🟢 레짐의 전방 수익률이 🔴 레짐보다 유의하게 높을 것 (순열검정 p<0.05)
- 커버 사이클: 2008 급락, 2010~13 침체, 2015~21 상승, 2022 급락, 2024~ 회복 (3+ 사이클)

**4-2. 결합 검증 (단지 레벨, 5년)**
- 기존 event_study에 레짐 축 추가: "🔴 보류 레짐에서 산 rv_z 시그널 vs 🟢 적기 레짐에서 산 rv_z 시그널"의 초과·절대수익 비교
- 여기서 변수 3·4(수급 축)의 한계 기여도 확인 → 무효 시 탈락

## 5. 스크리너 결합 (R-E)

## 검증 결과 (2026-08-14, backtest/regime_validation.py — §7 전체 구현 완료)

**§4-1 장기 검증 (2003~, 사이클 3개, M2 제외 후): 통과**
- 🟢 매수적기 월 이후 12M 지수수익: 평균 +6.2%, 양(+)비율 97.1% / 🔴 보류: -2.9%, 46.7%
- 격차 +9.1%p (12M), +9.6%p (24M), 순열검정 p<0.0001

**변수별 검증 (전방 지수수익과 Spearman, 12M)**
- ✅ 심리 0.59 > 수급 0.52 > 금리방향 0.38 > 지수모멘텀 0.36
- ❌ **M2 역방향(0.08/-0.19) → R-B 조건부 원칙에 따라 점수에서 탈락** (모니터링 컬럼만 유지)

**§4-2 결합 검증: 직교성 확인**
- rv_z 시그널의 절대수익은 레짐 의존(🟢 13.1% vs 🔴 7.6%/12M) — 레짐 게이트 가치 입증
- 그룹 대비 초과수익은 레짐 무관(6.4~7.6%p 일정) — 문제 1(타이밍)·문제 2(선택)의 분리가 실증됨

**현재 판정 (2026-07)**: 🟢 매수적기 (score +0.64, 6변수, 2026-02부터 6개월 연속 🟢)
