# [프로젝트 명] 요구사항 정의서

## 1. 프로젝트 목적 및 목표
* **목적:**주식 분석 시에 대부분 매크로지표를 이용해서 분석을 하고 있는 나인데 앞으로 개별주들,  특히 시가총액이 작은 개별주들(나스닥, 코스피, 코스닥 등) 상장사 분석을 위해서
네이버 종목 토론방 또는  커뮤니티. 크롤링을 통해서 감성 분석을 진행하고 대중의 심리와 반대되는 의사 결정을 해주는 오토마타 머신을 만들려고 해.
 그러면은 일반의 대중과 역행하는 의사 결정을 함으로써 시세 차익을 얻을 수 있겠다는 인사이트야. 

* **핵심 가치:**네이버 종목 토론방 또는  커뮤니티. 크롤링을 통해서 감성 분석을 진행

* **목표:** 일반의 대중과 역행하는 의사 결정을 함으로써 시세 차익을 얻을 수 있겠다는 인사이트야. 

## 2. 타겟 유저 및 페르소나
* **메인 유저:** 영준 (개발자),
* **사용 환경:** 모바일 접속 + 집 PC 서버 처리

## 3. 핵심 기능 요구사항 (Functional Requirements)
* [ ] **기능 1:** 네이버 종목 토론방 또는  커뮤니티. 크롤링을 통해서 감성 분석을 진행
* [ ] **기능 2:** 일반의 대중과 얼마나 역행하는 지표화 
* [ ] **기능 3:** 점수 기반 개별주 추천(인간지표)

## 4. 제약 사항 및 기술 스택
* **언어:** Python 3.12+ / TypeScript

* **인프라:** 로컬 PC (Tailscale 접속)
**서버: streamlit

## 5. UI/UX 요구사항
* **모바일 접속 시:** 최소한의 버튼으로 자동 실행 가능할 것
* **PC 화면:** 로그 모니터링이 가능할 것
