# [백로그] Family D — 한국 증시 현황 인포그래픽 (ADR 기준)

- **상태**: 미착수 — 착수 전 별도 브레인스토밍 세션 1회 필요(이 문서는 스펙이 아니라 잊지 않기 위한 착수 전 메모)
- **참고**: [[project-daily-market-dashboard]] Family D, 예시 이미지 1개 인스턴스 확인

## 알려진 것

- KOSPI/KOSDAQ ADR(등락비율) 1년 차트 + 현재값 + 해석·예상 문구.
- 한국 종시 개요(KOSPI/KOSDAQ 지수 + 외국인/기관/개인 수급).
- 외국인/기관 수급 동향 라인차트(최근 5거래일).
- 업종별 수익률(KOSPI, 6개 업종 막대).
- 시장 심리 게이지(냉각/중립/과열, ADR 기준 0~80/80~120/120+).
- 시장 전망(OODA), 주요 리스크 요인(Black Swan), 체크포인트.
- 독립형 1페이지, 발행 주기 불명(다른 3개와 달리 날짜별 반복 인스턴스를 아직 확보 못함).

## 착수 전 확인해야 할 핵심 질문

1. **ADR 계산 방법**: KOSPI/KOSDAQ 전 종목의 상승/하락 종목 수 비율(등락비율) 계산은 개별 티커 하나씩 받는 지금 방식과 근본적으로 다름 — 전 종목 일별 등락 데이터가 필요. KRX 데이터를 어디서 받을지(무료 소스 확인 필요, 유료라면 대안 필요).
2. **1년치 ADR 히스토리**를 어떻게 구할지 — 매일 스냅샷을 누적 저장하는 방식(자체 DB/CSV 축적)이 될 가능성이 높음. 이 경우 "오늘 하루" 리포트가 아니라 **장기간 데이터 축적이 선행 조건**이 됨 — B/C보다 착수 난이도가 높을 수 있음.
3. **업종별 수익률**은 KOSPI 업종 지수(있다면 그걸 쓰거나, 대표 종목 바스켓으로 근사)가 필요.
4. **발행 주기**: 다른 3개와 별도로 이 리포트만 언제 만들지(일일/주간/온디맨드) 확정 필요.

## 재사용 가능성

- 낮음 — 데이터 소싱 방식이 A/B/C와 가장 이질적(개별 티커 조회가 아니라 전종목 집계 필요). 별도 데이터 파이프라인으로 설계될 가능성이 높음.
