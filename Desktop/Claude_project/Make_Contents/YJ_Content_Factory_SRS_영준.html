영준 Lab

퀀트 투자 · 절세 · 재테크 · 가계부 콘텐츠 크리에이터 영준을 위한 독립 콘텐츠 자동화 시스템. 기존 퀀트 앱 YJ-Quant의 "오늘의 지침"을 Input으로 넣으면 유튜브 · 인스타 · 블로그 콘텐츠가 자동 생성된다. 절세·재테크·가계부 주제도 동일 구조로 처리한다.

채널 주제 · 퀀트 투자 · 절세 · 재테크 · 가계부 사용·개발 · 영준 (콘텐츠 + 시스템) 연동 자산 · YJ-Quant (Streamlit) 최종 수정 · 2026-06-09
01

프로젝트 개요

투자·재무 콘텐츠 제작의 반복 작업을 자동화하여 영준의 제작 시간을 줄이고, 검증 가능한 콘텐츠 자산을 축적하는 것을 목표로 한다. 윤진 Studio(요리·육아) 채널과는 완전히 분리된 독립 채널이다.

핵심 비전

퀀트 앱의 오늘의 지침(JSON)이나 절세·재테크·가계부 주제 카드만 넣으면, 유튜브 · 인스타 · 블로그 콘텐츠가 면책 조항까지 자동 포함되어 생성되는 프로그램. 최종적으로는 산출물을 기반으로 Vix(AI 영상 생성 툴)를 연동해 영상까지 자동 생성한다.

제작 주체

  • 영준 — 콘텐츠 기획·제작 + 시스템 개발
  • YJ-Quant 앱 운영자와 동일 인물 → 지침 데이터 직접 연동

산출 대상 플랫폼

YouTube (쇼츠·롱폼) Instagram (캐러셀·릴스) 네이버 블로그 → Vix 영상 (Phase 3)

핵심 자산 — 퀀트앱(YJ-Quant) 연동

영준은 이미 퀀트 앱 YJ-Quant (Streamlit 기반)를 운영 중이며, 매일 "오늘의 지침"(어떤 종목을 어떤 비율로 매수/매도할지)이 텍스트 + 화면 캡처 형태로 나온다. 이 지침 데이터를 그대로 Input으로 넣으면 콘텐츠가 자동 생성되어야 한다.

⚠️ 필수 규칙 — 투자·세무 콘텐츠의 모든 Output에는 "투자 권유가 아닙니다 / 일반 정보 제공 목적" 면책 조항이 자동 삽입되어야 한다.
🔱 채널 분리 원칙 — 영준 Lab은 윤진 Studio(요리·육아)와 브랜드·계정·시스템 탭이 완전히 분리된다. 두 채널은 서로 다른 톤·타깃·발행 일정을 가진다.
03

퀀트 콘텐츠 파이프라인

YJ-Quant 앱의 "오늘의 지침" 데이터를 Input으로 받아 5종 콘텐츠를 생성한다.

퀀트 지침 → 콘텐츠

YJ-Quant 앱의 일일 매매 지침(JSON) + 화면 캡처를 입력받아 자동 변환.

INPUT
  • 오늘의 지침 (JSON): 날짜·시장요약·전략명·매매시그널(종목+비율+근거)·리스크·핵심지표(VIX, F&G)
  • 퀀트앱 화면 캡처 (대시보드·레이더 차트)
  • (선택) 영준 코멘트
  • (선택) 시장 이슈 키워드
→
처리 · Claude
  • 지침 JSON 파싱
  • 면책 조항 자동 삽입
  • 5종 콘텐츠 생성
→
OUTPUT
  • E1 유튜브 영상 대본
  • E2 영상 구성/설계 전략
  • E3 인스타 캐러셀
  • E4 블로그 분석 글
  • E5 쇼츠/릴스 스크립트
E1
유튜브 영상 대본오프닝 후킹 · 시장 상황 · 전략 해설 · 근거 · 리스크 경고 · CTA
E2
영상 구성/설계 전략화면 구조 · 차트 배치 · 자막 스타일 · 참고 영상 스타일
E3
인스타 캐러셀5~7장 슬라이드 텍스트 · 후킹 표지 · 캡션+해시태그
E4
블로그 분석 글시장 분석 · 전략 설명 · 차트 삽입 위치 · 면책 조항 · SEO 태그
E5
쇼츠/릴스 스크립트60초 이내 대본
04

절세 · 재테크 · 가계부 콘텐츠

퀀트 외 3개 축은 "주제 카드"를 Input으로 받아 동일한 E1~E5 산출물 구조로 생성한다.

주제 카드 → 콘텐츠

정형 데이터가 없는 일반 주제. 영준의 경험·근거를 카드로 입력.

INPUT · 주제 카드
  • 주제 (예: 연말정산 13월의 월급)
  • 카테고리 (절세 / 재테크 / 가계부)
  • 핵심 포인트 3~5개
  • 타깃 (사회초년생 / 신혼부부 등)
  • 참고 링크 · 근거 자료
  • 영준 경험담 / 실제 사례
→
처리 · Claude
  • 채널 프로필 + 주제 카드 조립
  • 면책 조항 자동 삽입 (절세 = 세무 상담 아님)
  • 5종 콘텐츠 생성
→
OUTPUT
  • E1~E5 (퀀트와 동일 구조)

설계 원칙

  • Output은 퀀트 파이프라인의 E1~E5와 동일 구조 — 코드 재사용
  • 차이는 Input 포맷(지침 JSON ↔ 주제 카드)과 면책 문구 종류뿐
  • 가계부 콘텐츠는 시리즈/챌린지(예: 한 달 가계부 결산)로 묶어 시청자 리텐션 강화
⚠️ 절세 콘텐츠는 "세무 상담이 아닌 일반 정보", 재테크는 "투자 권유 아님" 면책을 카테고리별로 자동 분기한다.

시스템 아키텍처

영준 Lab 전용 단일 파이프라인 앱. 공통 엔진을 재사용하되, 윤진 Studio와는 별도 인스턴스/저장소로 운영한다.

06

개발 로드맵

퀀트 지침 MVP → 멀티 플랫폼 + 주제 콘텐츠 → AI 영상 생성 → 완전 자동화의 4단계 진화.

Phase 1 — MVP2주퀀트 지침 → 유튜브 대본+영상 전략
  • 퀀트 지침 JSON 파싱 + 면책 조항 자동 삽입
  • E1 유튜브 대본 + E2 영상 전략 생성
  • Streamlit 단일 채널 UI
Phase 2 — 멀티 플랫폼 + 주제 콘텐츠3주
  • E3 인스타 캐러셀 + E4 블로그 + E5 쇼츠 추가
  • 절세·재테크·가계부 주제 카드 파이프라인 추가
  • 카테고리별 면책 자동 분기
Phase 3 — Vix 영상 자동 생성4주
  • 산출물(대본+차트+자막) → Vix API → 완성 영상(.mp4) 자동 생성
  • 차트/지표 시각화 자동 삽입
Phase 4 — 완전 자동화장기
  • 지침 적중률 데이터 ↔ 콘텐츠 성과 연동 → 신뢰도 콘텐츠화
  • 유튜브/인스타 성과 데이터 연동 → 프롬프트 자동 최적화
  • 예약 발행 API 연동
