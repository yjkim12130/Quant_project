2. V93-A — ya_p_tks 누적 set 버그 수정

버그 수정  run_alpha()

버그 원인

Panic 구간에서 하락상위 / 상승상위 선별 방식을 사용할 때, 매수 차수(1차/2차/3차)마다 새로운 종목 리스트로 ya_p_tks를 덮어쓰고 있었습니다. 그 결과 3차 매수 이후에는 3차 시점의 선별 종목 수익률만 추적되어, 1·2차 매수로 보유한 종목의 실제 수익이 ya_p_val에 반영되지 않았습니다.

증상: Panic 3단계 매집 후 회복 국면에서 2번째/3번째 대비 1·2차 매수 비중이 많은 경우, 실제 수익보다 낮게 집계되어 최종 자산이 과소평가됨.

수정 내용

run_alpha() — ya_p_tks 초기화 & 누적 로직
- ya_p_val=0.0; ya_p_tks=[] # list — 매수마다 덮어씀 + ya_p_val=0.0; ya_p_tks=set() # [V93-A] 누적 set ... - else: ya_p_val+=ba_net; ya_p_tks=sel_tks # 덮어쓰기 + else: ya_p_val+=ba_net; ya_p_tks.update(sel_tks) # [V93-A] 누적

수익률 추적 방식 변경

v9.2 (버그)

# 3차 매수 후 ya_p_tks = 3차 선별 종목만
if ya_p_val > 0 and ya_p_tks:
    pa_av = [t for t in ya_p_tks if t in sr.columns]
    ya_p_val *= (1 + sr.loc[dt2, pa_av].mean())
# → 1·2차 매수 종목은 추적 누락

v9.3 (수정)

# ya_p_tks = 전 매수 차수 종목 합집합
if ya_p_val > 0 and ya_p_tks:
    pa_av = [t for t in ya_p_tks if t in sr.columns]
    ya_p_val *= (1 + sr.loc[dt2, pa_av].mean())
# → 모든 차수 종목의 평균 수익률 추적
적용 범위: panic_select = "하락상위" 또는 "상승상위"인 경우에만 해당. "시총기준"은 ya_p_tks를 사용하지 않아 영향 없음.

3. V93-B — fetch_ticker_signals 에러 캐시 회피

안정성 개선  fetch_ticker_signals()

문제 상황

@st.cache_data(ttl=86400) 데코레이터가 함수 전체를 감싸고 있어, yfinance 호출 실패로 발생한 에러도 24시간 캐시되었습니다. 네트워크 일시 장애나 API 레이트 리밋으로 실패한 티커가 다음 날까지 계속 에러 상태로 반환되는 문제가 있었습니다.

증상: 산업 분석 탭 또는 오늘의 신호 탭에서 특정 티커가 에러 아이콘으로 표시되고, 브라우저를 새로고침해도 최대 24시간 동안 복구되지 않음.

수정 구조 — 함수 분리

4. V93-C — RSI 분모 0 보호

버그 수정  add_ind(), _fetch_ticker_signals_inner()

RSI 계산 공식과 문제

RSI(Relative Strength Index)는 14일 평균 상승폭 g와 평균 하락폭 l의 비율로 계산합니다.

RSI = 100 − 100 / (1 + g / l)

시장이 연속 상승 구간에 있으면 14일간 하락이 전혀 없어 l = 0이 될 수 있습니다. 이때 g / l은 분모 0으로 NaN 또는 Inf가 발생했습니다.

증상: 강한 상승 초기 구간(예: 비트코인 급등 초반, 신규 상장 종목)에서 RSI가 NaN으로 계산되어 이후 지표 체인 전체에 NaN이 전파됨. 상태머신이 의도치 않게 기본값(Bull)으로 고정되거나 시뮬레이션 결과가 왜곡됨.

수정

add_ind() — RSI 계산
- df["RSI"] = 100 - (100 / (1 + g / l)) + df["RSI"] = 100 - (100 / (1 + g / (l + 1e-9))) # [V93-C] 분모 0 보호
1e-9의 의미: 극히 작은 epsilon(ε)을 더해 l=0일 때 g/ε → 매우 큰 수 → RSI ≈ 100이 됩니다. 실제 데이터에서 l이 0에 가까울 때와 사실상 동일한 결과(RSI ≈ 100, 과매수)를 유지하면서 NaN을 완전히 차단합니다.

동일한 수정이 _fetch_ticker_signals_inner() 내부의 개별 종목 RSI 계산에도 적용되었습니다.

5. V93-D — 레버리지 ETF Volatility Decay 모델

신규 기능  add_ind(), run_beta(), run_alpha()

레버리지 ETF의 실제 비용: Volatility Decay

레버리지 ETF(2x, 3x)는 매일 목표 배율을 재조정(일일 리밸런싱)합니다. 이 과정에서 시장 변동성이 클수록 장기 수익률이 이론 배율보다 낮아지는 Volatility Decay(변동성 감쇠) 현상이 발생합니다.

직관적 이해
2x ETF가 하루 +10% 이후 -10% 움직이면:
  - 원지수: 1.10 × 0.90 = 0.99 (-1%)
  - 2x ETF: 1.20 × 0.80 = 0.96 (-4%)

레버리지가 높을수록, 변동성이 클수록 이 손실이 누적됩니다.

수학적 모델

연속복리 근사에서 일일 레버리지 비용은 다음 수식으로 표현됩니다:

daily_decay = max(0, k² − k) · σ² / 2
변수의미코드
k레버리지 배율 (예: 2.0, 1.5)lv
σ²일일 수익률 분산 (30일 rolling std²)vd * vd
max(0, k²−k)k=1일 때 decay=0 보장 (비레버리지는 적용 안 함)max(0, lv*lv - lv)
k=1 (비레버리지): k²−k = 1−1 = 0 → decay = 0. 레버리지 없는 경우 비용 없음.
k=2: k²−k = 4−2 = 2 → decay = 2·σ²/2 = σ²
k=3: k²−k = 9−3 = 6 → decay = 6·σ²/2 = 3σ² (훨씬 큰 비용)

구현

add_ind() — Vol_30d 컬럼 추가
+ # [V93-D] 30일 rolling 변동성 (vol decay 계산용) + df["Vol_30d"] = df.get("Daily_Ret", p.pct_change()).rolling(30).std().fillna(0)
run_beta() / run_alpha() — 일일 루프 내 적용
+ vd = float(row.get("Vol_30d", 0.01) or 0.01) # [V93-D] ... + # [V93-D] 레버리지 일일 vol decay = max(0,k²-k)·σ²/2 + decay = max(0, lv*lv - lv) * (vd*vd) / 2 * _dc_mult if dr: ys *= 1 + dr*lv - max(0,lv-1)*(LEV_COST/TRADING_DAYS) + - decay # vol decay 차감
_dc_mult: include_costs 토글(V93-E)과 연동됩니다. OFF이면 _dc_mult=0.0으로 decay도 비활성화됩니다.

6. V93-E — 거래 비용 & ETF 운용보수 반영

신규 기능  전역 상수 + 전략 엔진 전체

새로운 전역 상수

# [V93-E] 현실적 비용 모델 (사이드바 include_costs 토글로 ON/OFF)
TRADE_COST = 0.0005   # 매수 시 0.05% (수수료 + 슬리피지)
ETF_TER    = 0.0020   # ETF 연간 운용보수 0.20% (일별 차감)

비용 종류

비용값적용 시점실제 의미
TRADE_COST 0.05% 매수 발생 시 (매일 적립 + Panic 매수) 증권사 수수료 + 호가 스프레드(슬리피지) 합산
ETF_TER 0.20%/년 매 거래일마다 일별 차감 ETF 운용 수수료 (Total Expense Ratio). S&P500 ETF 평균 수준
Vol Decay 변동성 의존 매 거래일 (V93-D) 레버리지 일일 리밸런싱 비용

적용 위치 (run_beta 기준)

# [V93-E] 비용 토글 — include_costs가 False면 모두 0
_tc      = TRADE_COST if include_costs else 0.0
_ter     = ETF_TER    if include_costs else 0.0
_dc_mult = 1.0        if include_costs else 0.0  # vol decay도 함께 제어

# 매일 적립 시 수수료 차감
ys += dst * (1 - _tc)            # ETF 적립 매수

# TER 일별 차감
ys *= 1 - _ter / TRADING_DAYS    # 0.20% / 252

# Panic 매수 시 수수료 차감
pb = min(yc * dr2, yc)
ys += pb * (1 - _tc)            # Panic 매수
